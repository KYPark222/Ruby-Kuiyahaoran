# 盤面物理設定

この設定は `app/assets/javascripts/pachinko_physics_config.js` に集約しています。数値はPNG/SVGの見た目に合わせた仮初期値で、実機の実測値ではありません。

## 座標と初期値

- 物理座標とSVGは `viewBox="0 0 1015 1550"` を共有します。PNGも1015×1550pxです。ブラウザ上の拡大縮小は盤面、SVG、玉Canvasに同じ比率で適用します。
- 玉半径8、釘衝突半径6、通常レール幅8、液晶ガード幅7（盤面座標単位）。釘の中心は`.physics-pin`のSVG属性から読み込みます。
- 重力、反発、摩擦、速度上限、固定時間ステップ、2分割のサブステップ、Matter.js反復回数は設定モジュールで調整します。
- 発射点は左下の `(145, 1280)`。角度は画面座標系で `-101.31°`、弱・中・強の初速はそれぞれ13.2、15.3、17.0です。
- 上記の数値と開口許容幅は見た目・動作確認用の仮設定です。実機計測値ではありません。

## 発射と物理設定の上書き

`PachinkoPhysicsConfig.values`を初期設定として使います。盤面ごとの上書きは `PachinkoPhysics.createSimulation({ ..., options })` に渡せます。発射時は `simulation.launchBall({ strength: "weak" | "medium" | "strong" })` を使います。発射方向と速度は生成時に一度設定し、その後の位置はMatter.jsが更新します。

## 入賞率の試行統計

具体的な目標入賞率は未指定なので初期値は `null` です。画面の「物理検証・入賞率」欄から入力・変更できます。稼働中のsimulationでは `simulation.stats.setTargetRate(目標パーセント)` を呼び、`simulation.stats.snapshot()`から目標値、完了試行数、入賞数、排出数、保留数、実測率、目標差、発射強度別結果、各試行のパラメータと時刻を取得できます。設定を解除するときは `setTargetRate(null)` を使います。集計はページ内メモリのみで、永続化しません。

実測率の分母は結果が確定した試行（入賞または盤面外への排出）のみです。流下中は保留に含まれ、手動削除はキャンセル扱いで分母から除外します。物理パラメータや玉の位置を確率で補正する処理はありません。
ページ表示時のデモ玉は `trackTrial: false` で、試行統計には含めません。実験玉は `simulation.launchBall({ strength: "medium" })` で登録します。

## 入賞判定とデバッグ

ヘソ開口はSVGの `[data-physics-role='entry-sensor']` 楕円（現状の座標 `(508, 1392)`、半径 `rx=23, ry=13`）を参照します。半径8の玉では、中心判定の許容楕円はおよそ `rx=15, ry=5` です。玉の中心が下向きにこの範囲を通過した時だけ一度入賞とし、玉をワールドから除去します。抽選・払い出しは接続しません。

開発用の衝突形状、釘円、ヘソ判定楕円、発射ベクトル、玉の速度ベクトルと状態を表示するには、URLに `?physicsDebug=1` を付けます。またはConsoleから `PachinkoPhysics.get(document.querySelector("[data-board-scene]")).setDebug(true)` を呼びます。通常表示では物理形状を重ねません。

## 未校正の箇所

PNGには部品の正確な深度や裏側形状がなく、SVGのレール線も一部は見た目用です。現在はSVGの役割付きレールと釘を独立した衝突体に近似しています。玉が液晶左右から下部へ回る経路やヘソまでの実測到達率は、複数条件で試行し、レール座標・釘座標・開口許容幅を再校正する必要があります。目標入賞率を指定するまでは、入賞率の合否判定は行いません。
